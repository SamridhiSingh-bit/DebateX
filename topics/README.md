# DebateX Topic Library

This folder contains the curated debate-topic collection
used by the DebateX application.

## Files

- topics.json: Contains all individual debate topics.
- categories.json: Contains topic category information.
- README.md: Documentation for this collection.

## Topic statistics

- Main topics: 100
- Bonus topics: 8
- Total topics: 108
- Categories: 11 main + 1 bonus

## Topic structure
Each topic contains:

- id: Unique topic identifier.
- title: Debate topic or motion.
- category: Topic category.
- difficulty: Beginner, Intermediate, or Advanced.
- enabled: Whether the topic is available.
- collection: Main or bonus.
